How do I add spreads to my Pickem Pool?

The Against the Spread game format allows you to set your pool to use CBS Sports-provided point spreads under the NFL, College, or NFL & College game types. This can be set from a computer or mobile device.

Spreads for the upcoming week's NFL games in Football Pick'em are usually posted by 12:00pm EST on Tuesday. Once released, they're final for the week. The original posted spread stays fixed and won't change.

If you need to update your game format from Straight Up to Against the Spread, click on Settings, then Pool Settings. From the following page, click the settings icon, then Edit Pool Settings. Scroll down to the Game Format section and select Against the Spread. Click OK to save your changes. We are no longer offering the option to set custom spreads for games.

Note: Once a player has saved picks, but prior to the start of the pool, this setting will be locked. You can unlock this setting by clearing out your pool's picks. Please see our How can I unlock my pool's settings? article by clicking here. If a setting is changed, an email will be sent to all pool members regarding the change. If standings have run for the first week of your pool, you will not be able to edit the Game Format setting.
